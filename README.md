# feuerwehr-fitness.de

Projektseite zum Forschungsprojekt „Körperliche Fitness, Gesundheit und Training von Feuerwehrleuten“ (Felix Sempf, Universität Vechta).

Statische Website ohne Build-Schritt:

- `index.html` – Startseite (deutsch), `en/index.html` – englische Fassung
- `impressum.html`, `datenschutz.html` – rechtliche Angaben
- `assets/` – Bilder, Poster, Schriften (lokal eingebunden, keine externen Dienste), CSS und das Skript für die Poster-Vergrößerung

Live unter https://feuerwehr-fitness.de (GitHub Pages). Die Übungsfotos sind von Wolters Kluwer lizenziert (Lizenz Nr. 6382340421354, gültig bis 5. November 2027).
